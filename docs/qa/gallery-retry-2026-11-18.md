# Gallery image recovery, 2026-11-18

A failed full-size image previously left only a broken-image display in the lightbox, without a retry action. Add a bilingual status and a 44px-minimum retry control. Hide only the failed image, preserving gallery position, previous/next, keyboard navigation and close. Retry remounts the image at the same source URL, and moves keyboard focus to the stage so removing the retry button does not strand focus. Errors that happen before hydration are detected from the image's complete/naturalWidth state as well as onError. Each photo has independent recovery state. No image sources or captions changed.

Validation: two new bilingual failure/retry checks fail against the old build, pass after the change. Typecheck/build, 71 unit/API tests and seven browser checks pass, including existing gallery keyboard and scroll-restoration checks. Failed image requests intentionally intercepted, then restored for retry. Actual image decode succeeds; navigation and Escape/focus restoration work afterward. Inspected 390px Arabic/English error-state screenshots. These show a simulated network failure, not an assertion that live photo files are broken.
